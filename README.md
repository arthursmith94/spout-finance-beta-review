# Spout Finance Beta Review

An independent technical teardown and hands-on review of the [Spout Finance](https://beta.spout.finance) beta — a protocol for buying tokenized US stocks on Solana and borrowing stablecoins against them at 0% interest, funded by a weekly covered-call program.

The review combines a docs-based economic teardown with a hands-on session against the live beta (Solana devnet, 11 September 2026): what the "0% interest" loan actually costs, where the documentation contradicts itself, live UX findings, and reproducible bug reports.
